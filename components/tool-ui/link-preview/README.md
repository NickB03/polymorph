# Link Preview

Renders an Open Graph-style card with optional image, favicon, title, description, and domain. Supports configurable aspect ratio and image fit.

## Files

- Public exports: `components/tool-ui/link-preview/index.ts`
- Serializable schema + parse helpers: `components/tool-ui/link-preview/schema.ts`

## Quick check

Run this after edits:

```bash
bun run test
```
