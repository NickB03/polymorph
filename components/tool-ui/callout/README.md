# Callout

Renders a styled aside block with an icon, optional title, and content text. Supports six variants: `info`, `warning`, `tip`, `success`, `error`, and `definition`, each with distinct colors and icons.

## Files

- Public exports: `components/tool-ui/callout/index.ts`
- Serializable schema + parse helpers: `components/tool-ui/callout/schema.ts`

bun run test
