# Troubleshooting

> **Audience:** New Developer | Operator

This page is the navigation hub for troubleshooting docs. Setup, runtime, and build/search/database fixes live in focused leaves.

## Setup Issues

Environment, port, SSL, and provider-enable failures are in the setup leaf. See [Troubleshooting Setup Issues](TROUBLESHOOTING-SETUP.md#setup-issues).

## Runtime Issues

Auth, share-page, Supabase timeout, and rate-limit failures are in the runtime leaf. See [Troubleshooting Runtime Issues](TROUBLESHOOTING-RUNTIME.md#runtime-issues).

## Build Issues

Lint, formatting, and TypeScript failures are in the build/search/database leaf. See [Troubleshooting Build Search and Database Issues](TROUBLESHOOTING-BUILD-SEARCH-DATABASE.md#build-issues).

## Search Issues

Search provider failures and empty results are in the build/search/database leaf. See [Troubleshooting Build Search and Database Issues](TROUBLESHOOTING-BUILD-SEARCH-DATABASE.md#search-issues).

## Database Issues

Migration and RLS failures are in the build/search/database leaf. See [Troubleshooting Build Search and Database Issues](TROUBLESHOOTING-BUILD-SEARCH-DATABASE.md#database-issues).

## Getting More Help

Escalation pointers are in the build/search/database leaf. See [Troubleshooting Build Search and Database Issues](TROUBLESHOOTING-BUILD-SEARCH-DATABASE.md#getting-more-help).
