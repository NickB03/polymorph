# Evals Quality Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a visual dashboard at `/evals` that shows AI quality scores, trends, and per-evaluator breakdowns — designed for non-technical users to glance at during demos.

**Architecture:** The evals service (Railway cron) already runs 7 evaluators and pushes results to Phoenix. We add a persistence step: after each experiment, write a summary row to a new `eval_summaries` table in Supabase. The Next.js app reads from this table (same DB it already uses) and renders visual components. Zero new dependencies — uses existing Recharts + shadcn.

**Tech Stack:** Drizzle ORM (schema + migration), Recharts (charts), shadcn/ui (cards, badges), SVG (score ring), Tailwind CSS v4 (design tokens)

```typescript
// Eval experiment summaries — written by evals service after each experiment run
export const evalSummaries = pgTable(
  'eval_summaries',
  {
    id: varchar('id', { length: ID_LENGTH })
      .primaryKey()
      .$defaultFn(() => generateId()),
    suite: varchar('suite', {
      length: VARCHAR_LENGTH,
      enum: ['capability', 'regression', 'traffic-monitor']
    }).notNull(),
    experimentName: text('experiment_name').notNull(),
    datasetName: text('dataset_name').notNull(),
    passRate: integer('pass_rate_bps').notNull(), // basis points 0–10000 (avoids float)
    evaluatorScores: jsonb('evaluator_scores')
      .$type<Record<string, number>>()
      .notNull(),
    totalCases: integer('total_cases').notNull(),
    phoenixUrl: text('phoenix_url'),
    createdAt: timestamp('created_at').notNull().defaultNow()
  },
  table => [
    index('eval_summaries_suite_created_at_idx').on(
      table.suite,
      table.createdAt.desc()
    ),
    uniqueIndex('eval_summaries_experiment_name_idx').on(table.experimentName),

    // RLS: readable by all authenticated users (aggregate data, not per-user)
    pgPolicy('authenticated_read_eval_summaries', {
      as: 'permissive',
      for: 'select',
      to: 'public',
      using: sql`true`
    }),
    // Insert/update restricted to service role (evals service bypasses RLS via direct connection)
    pgPolicy('service_insert_eval_summaries', {
      as: 'permissive',
      for: 'insert',
      to: 'public',
      withCheck: sql`true`
    })
  ]
).enableRLS()

export type EvalSummary = InferSelectModel<typeof evalSummaries>
```

Key design choices:

- `pass_rate_bps` stores as integer basis points (8500 = 85.00%) to avoid floating-point precision issues in Postgres
- `evaluator_scores` is JSONB like `{ "faithfulness": 0.85, "relevance": 0.92 }` — scores stay as 0–1 floats in JSON since they're read-only display values
- `experiment_name` has a unique index to prevent duplicate writes if the cron reruns
- No `userId` column — this is system-level data, not per-user

```typescript
import type { db as DbType } from './db'

export interface EvaluationRun {
  name: string
  error: string | null
  result: { score?: number | null; label?: string | null } | null
}

export function computeEvaluatorAverages(
  runs: EvaluationRun[]
): Record<string, number> {
  const groups = new Map<string, number[]>()

  for (const run of runs) {
    if (run.error || !run.result || run.result.score == null) continue
    const scores = groups.get(run.name) ?? []
    scores.push(run.result.score)
    groups.set(run.name, scores)
  }

  const result: Record<string, number> = {}
  for (const [name, scores] of groups) {
    result[name] = scores.reduce((a, b) => a + b, 0) / scores.length
  }
  return result
}

export async function persistEvalSummary(
  db: typeof DbType,
  params: {
    suite: string
    experimentName: string
    datasetName: string
    passRate: number // 0–1
    evaluationRuns: EvaluationRun[]
    totalCases: number
    phoenixUrl: string | null
  }
) {
  const evaluatorScores = computeEvaluatorAverages(params.evaluationRuns)
  const passRateBps = Math.round(params.passRate * 10000)

  await db.execute(
    `INSERT INTO eval_summaries (id, suite, experiment_name, dataset_name, pass_rate_bps, evaluator_scores, total_cases, phoenix_url)
     VALUES (gen_random_uuid(), $1, $2, $3, $4, $5, $6, $7)
     ON CONFLICT (experiment_name) DO NOTHING`,
    [
      params.suite,
      params.experimentName,
      params.datasetName,
      passRateBps,
      JSON.stringify(evaluatorScores),
      params.totalCases,
      params.phoenixUrl
    ]
  )
}
```

Key choices:

- `ON CONFLICT DO NOTHING` — idempotent; safe if the cron re-runs or retries
- Raw SQL because the evals service doesn't share the main app's Drizzle schema
- `db.execute` uses the same Drizzle `postgres-js` driver already in the evals service

```typescript
import { desc, eq } from 'drizzle-orm'

import { db } from '@/lib/db/queries'
import { evalSummaries } from '@/lib/db/schema'

import type {
  EvalDashboardData,
  EvalExperimentSummary,
  EvalTrendPoint
} from './types'

function toSummary(
  row: typeof evalSummaries.$inferSelect
): EvalExperimentSummary {
  const scores = row.evaluatorScores as Record<string, number>
  const values = Object.values(scores)
  const overallScore =
    values.length > 0 ? values.reduce((a, b) => a + b, 0) / values.length : 0

  return {
    suite: row.suite,
    experimentName: row.experimentName,
    passRate: row.passRateBps / 10000,
    evaluatorScores: scores,
    overallScore,
    totalCases: row.totalCases,
    phoenixUrl: row.phoenixUrl,
    createdAt: row.createdAt.toISOString()
  }
}

export async function getEvalDashboard(
  suite: string = 'capability'
): Promise<EvalDashboardData> {
  const rows = await db
    .select()
    .from(evalSummaries)
    .where(eq(evalSummaries.suite, suite))
    .orderBy(desc(evalSummaries.createdAt))
    .limit(30)

  const summaries = rows.map(toSummary)
  const latest = summaries[0] ?? null
  const previous = summaries[1] ?? null

  const trend: EvalTrendPoint[] = summaries.reverse().map(s => ({
    date: s.createdAt,
    score: Math.round(s.overallScore * 100),
    suite: s.suite
  }))

  return {
    latest,
    previous,
    trend,
    lastUpdated: latest?.createdAt ?? null
  }
}

export async function getAvailableSuites(): Promise<string[]> {
  const rows = await db
    .selectDistinct({ suite: evalSummaries.suite })
    .from(evalSummaries)

  return rows.map(r => r.suite)
}
```

```tsx
'use client'

import { cn } from '@/lib/utils'

interface ScoreRingProps {
  score: number // 0–100
  label: string
  size?: number
  className?: string
}

export function ScoreRing({
  score,
  label,
  size = 180,
  className
}: ScoreRingProps) {
  const strokeWidth = 12
  const radius = (size - strokeWidth) / 2
  const circumference = 2 * Math.PI * radius
  const progress = Math.min(Math.max(score, 0), 100) / 100
  const strokeDashoffset = circumference * (1 - progress)

  const color =
    score >= 80
      ? 'var(--success)'
      : score >= 60
        ? 'var(--warning)'
        : 'var(--error)'

  return (
    <div className={cn('flex flex-col items-center gap-2', className)}>
      <svg
        width={size}
        height={size}
        viewBox={`0 0 ${size} ${size}`}
        className="-rotate-90"
      >
        {/* Background ring */}
        <circle
          cx={size / 2}
          cy={size / 2}
          r={radius}
          fill="none"
          stroke="var(--border)"
          strokeWidth={strokeWidth}
          opacity={0.3}
        />
        {/* Score arc */}
        <circle
          cx={size / 2}
          cy={size / 2}
          r={radius}
          fill="none"
          stroke={color}
          strokeWidth={strokeWidth}
          strokeDasharray={circumference}
          strokeDashoffset={strokeDashoffset}
          strokeLinecap="round"
          className="transition-all duration-1000 ease-out"
        />
      </svg>
      {/* Score number overlaid in center */}
      <div
        className="absolute flex flex-col items-center justify-center"
        style={{ width: size, height: size }}
      >
        <span
          className="font-mono font-bold tabular-nums text-foreground"
          style={{ fontSize: size * 0.28 }}
        >
          {Math.round(score)}
        </span>
        <span
          className="text-muted-foreground"
          style={{ fontSize: size * 0.09 }}
        >
          out of 100
        </span>
      </div>
      <span className="text-sm font-medium text-muted-foreground">{label}</span>
    </div>
  )
}
```

```tsx
import { cn } from '@/lib/utils'

interface DeltaBadgeProps {
  current: number // 0–1
  previous: number | null // 0–1
}

export function DeltaBadge({ current, previous }: DeltaBadgeProps) {
  if (previous === null) return null

  const deltaPercent = Math.round((current - previous) * 100)
  if (deltaPercent === 0) return null

  const isPositive = deltaPercent > 0

  return (
    <span
      className={cn(
        'inline-flex items-center rounded-full px-1.5 py-0.5 text-xs font-medium tabular-nums',
        isPositive ? 'bg-success-bg text-success' : 'bg-error-bg text-error'
      )}
    >
      {isPositive ? '+' : ''}
      {deltaPercent}%
    </span>
  )
}
```

```tsx
'use client'

import { cn } from '@/lib/utils'

import { getEvaluatorLabel, getScoreColor } from '@/lib/evals/evaluator-labels'

import { DeltaBadge } from './delta-badge'

interface EvaluatorBarsProps {
  scores: Record<string, number> // 0–1
  previousScores: Record<string, number> | null
}

export function EvaluatorBars({ scores, previousScores }: EvaluatorBarsProps) {
  const entries = Object.entries(scores).sort(
    ([, a], [, b]) => b - a // highest score first
  )

  if (entries.length === 0) {
    return (
      <div className="text-sm text-muted-foreground">No evaluator data yet</div>
    )
  }

  return (
    <div className="space-y-3">
      {entries.map(([key, score]) => {
        const percent = Math.round(score * 100)
        const color = getScoreColor(score)
        const previousScore = previousScores?.[key] ?? null

        return (
          <div key={key} className="space-y-1">
            <div className="flex items-center justify-between text-sm">
              <span className="text-foreground font-medium">
                {getEvaluatorLabel(key)}
              </span>
              <div className="flex items-center gap-2">
                <DeltaBadge current={score} previous={previousScore} />
                <span className="font-mono text-foreground tabular-nums">
                  {percent}
                </span>
              </div>
            </div>
            <div className="h-2 w-full rounded-full bg-muted">
              <div
                className={cn(
                  'h-full rounded-full transition-all duration-1000 ease-out',
                  color === 'success' && 'bg-success',
                  color === 'warning' && 'bg-warning',
                  color === 'error' && 'bg-error'
                )}
                style={{ width: `${percent}%` }}
              />
            </div>
          </div>
        )
      })}
    </div>
  )
}
```

Create `components/evals/dashboard.tsx`:

```tsx
'use client'

import type { EvalDashboardData } from '@/lib/evals/types'

import { EvaluatorBars } from './evaluator-bars'
import { ScoreRing } from './score-ring'
import { TrendChart } from './trend-chart'

interface EvalsDashboardProps {
  data: EvalDashboardData
}

export function EvalsDashboard({ data }: EvalsDashboardProps) {
  const { latest, previous, trend } = data

  if (!latest) {
    return (
      <div className="flex flex-col items-center justify-center gap-4 py-20 text-center">
        <h2 className="text-xl font-semibold text-foreground">
          No evaluation data yet
        </h2>
        <p className="max-w-md text-sm text-muted-foreground">
          Evaluation results will appear here after the next scheduled eval run.
          Evals run automatically once every 24 hours.
        </p>
      </div>
    )
  }

  const overallPercent = Math.round(latest.overallScore * 100)
  const previousPercent = previous
    ? Math.round(previous.overallScore * 100)
    : null
  const delta =
    previousPercent !== null ? overallPercent - previousPercent : null

  // Plain-language summary
  const summaryParts: string[] = []
  if (delta !== null && delta !== 0) {
    summaryParts.push(
      delta > 0
        ? `Quality improved ${delta} points since last run.`
        : `Quality dropped ${Math.abs(delta)} points since last run.`
    )
  }

  // Find weakest evaluator
  const weakest = Object.entries(latest.evaluatorScores).sort(
    ([, a], [, b]) => a - b
  )[0]
  if (weakest && weakest[1] < 0.7) {
    const { getEvaluatorLabel } = require('@/lib/evals/evaluator-labels')
    summaryParts.push(
      `${getEvaluatorLabel(weakest[0])} needs attention (${Math.round(weakest[1] * 100)}%).`
    )
  }

  const lastRun = new Date(latest.createdAt).toLocaleString('en-US', {
    month: 'short',
    day: 'numeric',
    hour: 'numeric',
    minute: '2-digit'
  })

  return (
    <div className="mx-auto max-w-4xl space-y-8 p-6">
      {/* Header */}
      <div className="space-y-1">
        <h1 className="text-2xl font-bold text-foreground">
          Quality Dashboard
        </h1>
        <p className="text-sm text-muted-foreground">
          Last evaluated {lastRun} &middot; {latest.totalCases} test cases
          {latest.phoenixUrl && (
            <>
              {' '}
              &middot;{' '}
              <a
                href={latest.phoenixUrl}
                target="_blank"
                rel="noopener noreferrer"
                className="text-info hover:underline"
              >
                View in Phoenix
              </a>
            </>
          )}
        </p>
      </div>

      {/* Summary banner */}
      {summaryParts.length > 0 && (
        <div className="rounded-lg border border-border bg-card p-4 text-sm text-foreground">
          {summaryParts.join(' ')}
        </div>
      )}

      {/* Top row: Score ring + Trend chart */}
      <div className="grid gap-6 md:grid-cols-[auto_1fr]">
        {/* Score ring */}
        <div className="flex justify-center">
          <div className="relative">
            <ScoreRing
              score={overallPercent}
              label={
                overallPercent >= 80
                  ? 'Excellent'
                  : overallPercent >= 60
                    ? 'Good'
                    : 'Needs Work'
              }
            />
          </div>
        </div>

        {/* Trend chart */}
        <div className="rounded-lg border border-border bg-card p-4">
          <h2 className="mb-3 text-sm font-medium text-muted-foreground">
            Score Trend
          </h2>
          <TrendChart data={trend} />
        </div>
      </div>

      {/* Evaluator breakdown */}
      <div className="rounded-lg border border-border bg-card p-4">
        <h2 className="mb-4 text-sm font-medium text-muted-foreground">
          Evaluator Breakdown
        </h2>
        <EvaluatorBars
          scores={latest.evaluatorScores}
          previousScores={previous?.evaluatorScores ?? null}
        />
      </div>
    </div>
  )
}
```

- [ ] **Step 2: Fix the `require` call**

The `require` in the summary section won't work in a client component. Replace the `require` block with a direct import. The `getEvaluatorLabel` import should be at the top of the file:

```typescript
}
```
